# Code of Conduct

> Правила поведения в Issues, PR и обсуждениях. Нарушаешь - забаню без предупреждения.

## Наши принципы

1. **Уважение.** Общайся нормальным языком. Оскорбления, токсичность, агрессия - не приветствуются. Аргументируй мысли, не переходи на личности.
2. **Конструктивность.** Хочешь что-то изменить или предложить - объясни зачем и что это даст. Бессмысленные сообщения игнорируются.
3. **Терпение.** Это проекты в свободное время. Ответы могут быть не мгновенными. Не спамь в Issues, не дублируй сообщения. Хочешь ускорить процесс - отправь качественный PR сам.
4. **Честность.** Не выкладывай чужой код как свой. Указывай источники.
5. **Ответственность.** Отправляешь код - отвечаешь за него. Если твой код сломает стабильность - это твоя ответственность.

## Запрещено

- Оскорбление участников или контрибьютеров (включая владельца)
- Спам, флуд, оффтоп в Issues и PR
- Публикация вредоносного кода или бэкдоров
- Попытки обойти защиту, баны, ограничения
- Публикация секретов: токены, ключи, пароли, сессии, базы данных
- Дискриминация по любому признаку
- Запросы, нарушающие действующие законы

## Следствия

Нарушение правил приводит к:

1. Предупреждению
2. Бану навсегда

## Вопросы?

Если ведёшь себя адекватно - проблем не будет.
