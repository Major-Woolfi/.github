# Промпт для DeepSeek

## Задача - перевод языкового пакета формата `{lang_code}.json` на несколько языков

ТЗ:

Требуется перевести языковой пакет бота, представленный в формате JSON, на следующие языки: русский, английский, белорусский, немецкий, японский, польский и китайский. Переводы должны быть точными и сохранять исходный смысл, названия и ключи. Также необходимо учитывать контекст.

Дополнительно, необходимо отсортировать ключи переводов в алфавитном порядке и использовать этот порядок для каждого языка. Важно, чтобы структура JSON оставалась неизменной, все ключи были сохранены и шаблоны вида `{*}` (например, `{username}`) оставались без изменений в переводах.

> Пример исходного файла, содержащего все неотсортированные ключи и их значения предоставлен приложением на русском языке (файл `ru.json`)
> В ответе долждны быть предоставлены переводы в формате JSON соответствующих ТЗ, с подписанием каждого файла в диалоге с названием файла, для которого был выполнен перевод (например: `ru.json`, `en.json`, `be.json`, `de.json`, `ja.json`, `pl.json`, `zh.json`).
